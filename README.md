# 🎙️ Голосовой ассистент на Python

Простой голосовой ИИ для управления Windows через голосовые команды.

---

## 🚀 Возможности
- Управление системными окнами (открыть, свернуть, закрыть)
- Управление звуком (громкость, mute)
- Работа с текстом (копировать, вставить, удалить)
- Движение курсора и клики
- Скриншоты
- Поиск в Google
- Открытие приложений (Telegram, браузер, блокнот)
- Переключение языка и выполнение горячих клавиш
- Голосовой синтез речи (TTS) и распознавание команд (STT)
- ИИ сделан очень легко, что позволяет просто и быстро добавлять новые функции
